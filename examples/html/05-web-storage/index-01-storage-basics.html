面板 4 · 容量压测（QuotaExceededError）

每次 setItem 写入约 100KB 的字符串，循环累加直到配额耗尽。浏览器通常给每个源 5~10MB， 超限时 setItem 抛 QuotaExceededError——必须 try/catch，否则异常会打断业务代码。
