示例 4 · eagerness 三档策略对比

conservative hover / pointerdown 时触发
moderate 链接进入可视区时触发
eager 页面加载完立即触发

当前页面使用 moderate 策略。
conservative 适合移动端（hover 退化为 touchstart）；
eager 资源消耗最大，仅适合极小站点或极重要下一页。

示例 5 · 与 View Transitions 配合实现「瞬时导航 + 动画」

最佳实践组合：

  1. 列表页用 Speculation Rules 预渲染详情页
  2. 详情页 CSS 声明 @view-transition { navigation: auto; }
  3. 列表与详情页共享元素使用相同 view-transition-name
  4. 用户点击 → 页面已渲染完毕（瞬时）→ View Transitions 执行共享元素补间动画

结果：纯 MPA 架构获得超越多数 SPA 的导航体验，无需前端路由框架。
