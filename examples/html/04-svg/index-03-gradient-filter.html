SVG 渐变与滤镜

渐变定义在 <defs> 里、用 fill="url(#id)" 引用；滤镜是 fe 原语组成的 "数据处理管道"，in/result 就是管道里的变量名。悬停第一个按钮试试 CSS 联动。

① 线性渐变（hover 换色联动）

悬停整块 SVG：CSS 修改 stop-color，渐变整体平滑变色—— 内联 SVG 的 stop 是 DOM 节点，可直接被 CSS 控制。

② 径向渐变球体

radialGradient 的 cx/cy/r 全是"包围盒百分比"； 把中心移出正中即可制造打光角度，这是画"球"最省事的办法。

③ 霓虹发光（blur + merge）

发光 = feGaussianBlur 模糊 + feMerge 把模糊层和原图叠放。 注意 filter 区域已放大到 260%，否则光晕会被裁成方块。

④ 投影（四段滤镜管道）

管道：SourceAlpha 模糊 → 偏移 → feFlood 灌色 → composite 裁形 → merge 叠放。 比 CSS box-shadow 繁琐，但每个环节都可自定义。
