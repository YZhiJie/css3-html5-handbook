viewBox 缩放原理 与 描边动画

viewBox 是"逻辑图纸"，width/height 是"相框"，preserveAspectRatio 决定装裱方式； 而 stroke-dasharray/-offset 则让任意线条"自己画出来"——这是 SVG 最经典的两件事。

同一份 viewBox="0 0 100 50"，放进 300×100 的相框

xMidYMid meet
完整显示 · 左右留白
xMidYMid slice
铺满相框 · 上下裁切
none
强行拉伸 · 已变形

CSS 描边动画：循环进度环（纯 CSS，无 JS）

dasharray = 周长(2πr≈283)，dashoffset 从 283 → 0， 实线段像"爬虫"一样爬进视口，圆环就从 0% 长到 100%。 transform: rotate(-90deg) 让起点转到 12 点方向。

JS 描边动画：心电图折线（getTotalLength 精确配速）
