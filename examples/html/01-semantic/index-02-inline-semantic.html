③ strong / em / b / i：视觉相近，语义不同

悬停（或 Tab 聚焦）任一卡片，查看"读屏视角"对它的解读。选错标签 = 给听障用户错误的重音与轻重信号。

同场加映：原价 ¥399（不再准确）与 ¥399¥299（编辑修订）、 页脚 © 附属细则 —— 划线价用 s，改价留痕用 del/ins。

④ mark：与"当前关注点"相关的高亮

mark 的语义是"这段文字因为与用户当前的操作相关而被标出"——典型场景就是搜索结果命中高亮，而不是"我觉得重要就标黄"。

语义化标签让 HTML 从一堆 div 变成机器可读的文档结构。语义化的收益里，无障碍的确定性远高于 SEO 的不确定性。
