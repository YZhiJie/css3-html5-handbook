    标签 语义 不要混用
    mark 语境相关的高亮（搜索/批注） 永久强调用 strong
    small 附属细则：版权、免责、脚注 只为了变小用 CSS
    abbr 缩写，title 给全称 —
    kbd 用户输入（按键/命令） 程序输出用 samp
    samp 系统/程序输出 代码本身用 code

    slot 思路简述

    <slot> 是 Shadow DOM 的内容投影槽：组件模板里写 <slot name="title"> 占位，使用方传 <span slot="title"> 即投射到槽内。template 解决"结构复用"， slot 解决"占位填充"，二者在自定义元素中配合。
