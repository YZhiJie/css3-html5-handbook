示例 01 · <dialog> 原生对话框

模态 showModal（遮罩 / ESC / 焦点陷阱 / method=dialog 返回值）与非模态 show 侧栏 —— 浏览器原生造好的轮子。

⚠️ 当前浏览器不支持 <dialog>（建议 Chrome 37+/Edge 79+/Firefox 98+/Safari 15.4+）。页面交互将不可用，请更换现代浏览器体验。

舞台区（背景内容）

打开模态后：点不到这些控件、Tab 键无法离开对话框、读屏器也读不到这里；打开非模态侧栏后：一切照常可操作。

操作

建议实测路径：

  • 打开模态后狂按 Tab / Shift+Tab：焦点只在框内三要素循环（焦点陷阱）。
  • 按 ESC：触发 cancel 后关闭（等于取消）。
  • 点击半透明遮罩：关闭并返回 "backdrop"（注意误触说明）。
  • 不填原因直接点确认：浏览器内建 required 拦截，框不会关闭。
  • 关闭后观察：焦点自动归还到触发按钮。

showModal vs show 对照

  • showModal()：top layer + ::backdrop + ESC + 焦点陷阱 + 背景移出可访问性树。
  • show()：普通显示，无遮罩、ESC 不关、焦点自由，可与主页面同时操作。
  • method="dialog"：表单提交不发请求，按钮 value 写入 returnValue。
  • 遮罩点击关闭是社区惯例：在框内按下、框外松手可能误触，破坏性操作慎用。
