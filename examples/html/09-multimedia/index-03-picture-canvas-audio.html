示例 03 · picture / captureStream / Web Audio

本页完全零网络依赖：图片用内联 SVG data URI 自绘，视频流来自 Canvas 画布，音频由振荡器合成。

① picture 响应式：art direction（不同构图，不只是不同分辨率）

监听视口…

把窗口拖窄到 640px 以下再拖宽，观察构图切换。picture 的选择在"布局阶段"完成，浏览器用 matchMedia 同款条件评估 source； 是真正的渲染元素与最终回退。

② Canvas 动画变成视频流（captureStream，零媒体文件）

源头：Canvas 2D 动画（requestAnimationFrame 驱动）

接收端：video 元素（srcObject = canvas.captureStream()）

captureStream 把画布每一帧作为 MediaStream 输出，可喂给 video、WebRTC、MediaRecorder 录制。Firefox 不支持 canvas.captureStream，脚本已做特性检测并提示。

③ Web Audio 音频可视化（振荡器合成 → 频谱 + 示波器）

频谱（AnalyserNode.getByteFrequencyData，fftSize=512）

示波器（getByteTimeDomainData，波形形状直观反映方波/锯齿差异）

链路：OscillatorNode(发声) → GainNode(音量) → AnalyserNode(分析) → destination(输出)。生产中用 ctx.createMediaElementSource(video) 桥接真实媒体元素后接同样的分析链。注意 AudioContext 必须在用户手势内 resume——这就是自动播放策略在音频侧的形态。
