details 与 summary 进阶

原生折叠面板 · 互斥手风琴 · ::details-content 动画 · 零 JS

✅ 当前浏览器支持 ::details-content ⚠️ 当前浏览器不支持 ::details-content，示例 3 将无动画（功能正常）

示例 1 · 基础折叠（零 JS）

什么是 HTML5？
HTML5 是 HTML 的第五次重大修订，新增语义化标签、表单增强、多媒体、Canvas、Web Storage 等能力。
details 需要 JS 吗？
不需要。浏览器原生处理展开/收起、键盘交互（Enter/Space）和屏幕阅读器。

open 属性控制默认展开；summary 必须是第一个子元素。

示例 2 · 互斥手风琴（name 属性）

如何申请退款？
订单页点击「申请退款」，7 天内无理由。
支持哪些支付方式？
微信、支付宝、云闪付、银行卡。
发票如何开具？
个人/企业发票均支持，下单后 30 天内申请。

相同 name="faq" 的 details 自动互斥，同时只开一个。

示例 3 · ::details-content 平滑动画

点击展开（平滑高度动画）

Chrome 131+ / Safari 18.4+ / Firefox 136+ 支持 ::details-content 伪元素。

配合 interpolate-size: allow-keywords，height: auto 也可平滑过渡。

不支持时退化为瞬时展开，功能不受影响。

示例 4 · 与 View Transitions 配合

展开时触发 View Transition

toggle 事件里调用 document.startViewTransition()，

浏览器自动对展开/收起做快照补间动画。

需浏览器同时支持 View Transitions 和 ::details-content。
