<dialog> 元素

showModal / show / close · ::backdrop · form method="dialog" · closedby

✅ 当前浏览器支持原生 dialog。模态打开后：页面背景自动惰性化、焦点圈禁在弹窗内、Esc 可关闭。 ⚠️ 当前浏览器不支持 dialog（Chrome 37+ / Safari 15.4+ / Firefox 98+）。

示例 4 · 进出场动画（@starting-style 三件套）

平滑进出场

打开：从 translate 20px + 透明 上浮淡入；关闭：反向播完再退出 top layer。遮罩同步淡入淡出。

三件套：终态 + :not([open]) 离场态 + @starting-style 入场起点；display/overlay 挂 allow-discrete。详见 CSS 篇 22。
