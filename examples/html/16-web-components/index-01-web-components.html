Web Components 入门

template · slot · Custom Elements · Shadow DOM 封装

1. template：惰性 HTML 模板

template 内内容不渲染、不执行。点击「克隆模板」才会实例化。

template 内的 script 不执行、图片不加载——只有克隆到文档后才会激活。

2. 自定义元素 + 插槽：卡片组件

<neon-card> 是自定义元素，内部用 Shadow DOM + slot 分发内容。 样式完全隔离，外部 class 和 CSS 不影响它。

CSS 容器查询

组件不问屏幕宽度，只问容器尺寸。同一张卡片放进侧栏竖排、放进主区横排。

 View Transitions

浏览器原生页面转场动画，无需 JS 计算布局差异。MPA 跨页转场也能用。

使用方式：<neon-card><span slot="title">...</span></neon-card>。 组件内部样式通过 Shadow DOM 隔离，slot 内容投影到指定位置。

3. 霓虹按钮：完全封装的样式

<neon-button> 的样式完全在 Shadow DOM 内，外部任何样式都无法覆盖它。 即使外部写 button { background: red; } 也无效。

默认按钮 幽灵按钮 危险按钮

CSS 自定义属性（--*）是穿透 Shadow DOM 的唯一方式—— 组件内部声明 background: var(--btn-bg, #22d3ee)，外部可以设 neon-button { --btn-bg: pink; }。

4. 生命周期：connectedCallback / attributeChangedCallback

<live-counter> 监听 data-count 属性变化，自动更新显示。 点击下方按钮改变属性值。

attributeChangedCallback 在属性值变化时触发， observedAttributes 声明要监听的属性名数组。
