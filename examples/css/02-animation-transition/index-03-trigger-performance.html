① 三种触发方式

hover：纯 CSS、双向自动；class 切换：JS 控制时机，最常用； IntersectionObserver：滚动到可视区才触发，营销页/信息流入场的标配。 第三张卡在下方空白区——向下滚动即可看到它入场。

② 性能对照：动 left（重排）vs 动 transform（合成）

两条轨道时长相同、路程相同。区别只在被动画的属性： left 每帧触发 Layout→Paint；transform 只更新合成层的矩阵， 由 GPU 完成。用 DevTools → Performance 录制对比，橙色轨道每帧都有紫色的 Layout 条。

反面：transition: left（每帧重排）

正面：transition: transform（仅合成）

③ 布局抖动（layout thrashing）现场演示

同一个循环里交替"读 offsetHeight → 写 height"会强制浏览器每次读都同步重排； 修正法是读写分离：先批量读完，再批量写。点击两个按钮对比耗时与柱状图动画。
