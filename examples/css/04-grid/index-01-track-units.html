轨道尺寸：fr / minmax / auto-fit vs auto-fill

Grid 的响应式核心全部写在 grid-template-columns 这一行里。

1. auto-fill vs auto-fit（拖动滑杆改变容器宽度）

固定放 3 个项目。容器足够宽（能装 6 列）时： auto-fill 保留 3 条空轨道（卡片不被拉伸）； auto-fit 把空轨道折叠为 0，3 张卡片拉伸铺满整行。

2. 1fr 不是严格等分（min-content 下限）

点"注入超长单词"后：1fr 1fr 的两列不再等宽—— fr 轨道的下限是内容 min-content；换成 minmax(0, 1fr) 把下限钳到 0，恢复严格等分。
