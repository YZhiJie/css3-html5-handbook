stretch 时项目块被拉满整个格子（拉伸的只有非 auto 尺寸的盒子）； 这是 place-items 最常用的四个值。最速记法：place-items: center = 格子内绝对居中。

2. place-content：整个网格在容器里怎么分空隙

固定轨道总尺寸 < 容器尺寸 → 剩余空隙由 place-content 分配。 注意它与 place-items 的区别：content 管"轨道群"，items 管"格子里的项目"。

3. 嵌套网格 → 子网格 subgrid：跨卡片行对齐

A 卡标题一行、B 卡标题两行。 关（独立嵌套）：两卡的"描述区"起点各自为政； 开（subgrid）：两卡标题/正文落在同一条父网格行线上，肉眼严格对齐。

A 卡：短标题

描述文字。A 卡标题只有一行。

B 卡：这是一个长标题它一定会折行变成两行的高度

描述文字。B 卡标题折成两行——独立嵌套时 A 卡的描述区会显得"偏高"。

subgrid 写法三要素：父网格提供公共行轨道 → 卡片 grid-row: span 3 占轨 → 卡片 grid-template-rows: subgrid 透传。不支持的浏览器自动回落为独立嵌套网格 + min-height 兜底。
