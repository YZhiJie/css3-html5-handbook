timeline-scope 示例 — 滚动时此指示器脉冲，由命名时间轴 --page-scroll 驱动。 滚动容器在父级声明 scroll-timeline-name，当前元素通过 timeline-scope 跨层级使用。

示例 · 卡片进入视口动画（view() + animation-range）

entry 0% entry 100%

元素底边刚进入视口时动画开始（0%），元素顶边到达视口顶边时动画结束（100%）。这是最常用的进出场触发区间。

感知均匀的进度

动画进度与滚动位置线性对应，不受时间影响。快速滚动时动画加速，慢速滚动时减速——这是与时间驱动动画的本质区别。

合成器线程运行

滚动驱动动画在合成器线程执行，不受主线程 JS 阻塞影响。即使页面在加载大量数据，滚动动画依然流畅。

更多卡片

animation-range: cover

cover 0% cover 100%：元素从进入视口底部到离开视口顶部的整个过程。适合持续性的滚动效果（如视差）。

animation-range: contain

contain 0% contain 100%：元素完全可见的期间。适合元素完全进入后才开始动画的场景。

animation-range: exit

exit 0% exit 100%：元素离开视口的过程。适合"离开时淡出"的效果。

注意：本页面所有动画均由 CSS animation-timeline 驱动，零 JavaScript。 开启系统「减少动画」偏好（prefers-reduced-motion）后所有动画自动降级为静态。 浏览器兼容性：Chrome 115+ / Firefox 110+ / Safari 26+。
