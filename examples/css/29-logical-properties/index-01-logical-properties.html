CSS 逻辑属性

inline-start · block-end · 逻辑简写 · RTL 自动适配

演示 1 · RTL 语言自动适配

LTR：左间距 16px，左对齐，左边框青色
RTL：右间距 16px，右对齐，右边框青色（自动适配）

margin-inline-start 在 LTR 是左边距，RTL 是右边距——一套代码适配两种方向。

演示 2 · 垂直书写模式

竖排文字：inline-size 控制高度，block-size 控制宽度

writing-mode: vertical-rl 时，inline-size = height，block-size = width。

演示 3 · 逻辑简写

逻辑简写卡片
margin-inline: auto 水平居中

margin-inline = margin-inline-start + margin-inline-end；inline-size = width。

演示 4 · 物理 vs 逻辑对比

物理属性（LTR 固定）
margin-left: 16px
border-left: 4px
RTL 下全错
逻辑属性（自动适配）
margin-inline-start: 16px
border-inline-start: 4px
RTL 自动翻转

左边物理属性在 RTL 下间距和边框方向全错；右边逻辑属性自动适配。
