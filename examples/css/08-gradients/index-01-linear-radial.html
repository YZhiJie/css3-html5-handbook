linear / radial 渐变实验台

拖参数、加色标、开条纹——所有变化实时反映在预览与生成的 CSS 代码里。

① linear-gradient 实验台

角度以 0deg = 向上、顺时针增大（90deg 向右）。勾选条纹模式后， 色标会按等距 hard-stop 生成（相邻两色位置相同 → 锐利分界），这是画条纹的全部原理。
90deg
预览：随左侧参数实时更新（渐变没有固有尺寸，天然铺满容器并随其缩放）

② radial-gradient 实验台（点击预览图移动中心）

尺寸关键字决定"最后一个色标落在哪"：farthest-corner（默认）延伸到最远的角、 closest-side 只到最近的边（做局部光斑常用）。形状切换 circle / ellipse 观察等色线是"同心圆"还是"贴着盒子比例的同心椭圆"。
