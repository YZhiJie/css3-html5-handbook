① conic-gradient：色轮与纯 CSS 饼图

conic 的色标是角度而非长度。饼图的"接力写法"： conic-gradient(#4361ee 0 calc(var(--p) * 3.6deg), #e9edf5 0)—— 第二个色标起点写 0 会被钳制到前一段终点，自动补满 360°。 拖动滑杆改变占比，观察饼图与中心数字同步变化。

③ 角度盘：from 起始角交互演示

from <angle> 决定色标循环的起点方向。这里把 from 抽成变量 --from，拖滑杆即转动整个扇区盘；配合 animation 动画 --from（需 @property 注册）即可做加载转盘。

读法：0° 在正上方，顺时针为正。from 30deg 表示第一扇区从"3 点钟偏上 30°"开始铺。
延伸：真实加载器常用 repeating-conic-gradient(var(--brand) 0 40deg, transparent 40deg 90deg) + 遮罩环，比 border 旋转更轻。
