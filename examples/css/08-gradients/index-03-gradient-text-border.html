渐变文字 / 渐变边框 / 渐变动画

三种文字玩法、三种边框方案、两条动画正路——每一条都注明降级行为。

① 渐变文字（background-clip: text）

原理：把背景图裁剪到字形里，再把文字填充色设为透明。三件套缺一不可： background-clip: text（前缀+标准双写）、 -webkit-text-fill-color: transparent、兜底 color。

流动渐变大标题：底图 300% 宽，position 循环位移

彩虹描边字 — 用 ::before 复制文字垫 stroke 层

右端淡出的消隐字：渐变到 transparent 即可裁掉笔画尾部

② 渐变边框：border-image vs 双层背景法

左卡的直角就是 border-image 的代价——它不支持 border-radius。 生产环境圆角卡片一律用双层背景法：padding-box 实色内层盖住 border-box 渐变外层的中心，只露出一圈边框。
方案 A · border-image border: 5px solid;
border-image: linear-gradient(…) 1;

注意四角：被切成直角，border-radius 失效。适合直角设计或大屏氛围条。
方案 B · 双层背景法（推荐） border: 5px solid transparent;
background: 实色 padding-box, 渐变 border-box;

圆角完美、支持多段渐变；唯一成本是 background 声明较啰嗦。
方案 C · 旋转流光边框 conic 渐变角度由 @property 注册的 --angle 驱动，keyframes 里动画该变量。

不支持 @property 的浏览器边框静止（可接受的优雅降级）。

③ 渐变 + 动画的两条正路

background-image 是离散值不可过渡。动画渐变只有两条正路： 动 background-position（超宽底图位移），或用 @property 注册类型化变量后动画变量。
方式 a · position 位移（兼容到渐变本身的支持度）
底图 300% 宽，动 position；alternate 来回避免循环接缝跳变。
方式 b · @property 动画角度（Chrome 85+ / Safari 16.4+ / Firefox 128+）
keyframes 直接写 --angle: 360deg；已注册的类型变量会被插值。
