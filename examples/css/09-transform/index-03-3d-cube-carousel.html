3D 立方体 / 3D 轮播 / 层深视差

三个经典 3D 场景：拼装口诀 + 拖拽交互 + translateZ 层深，全部纯 CSS + 原生 JS。

① 六面立方体：自动旋转 + 拖拽

拼装口诀"先转正、再推出"：rotateY(90deg) translateZ(65px) 把面转到朝右再推出半边长。 推出距离 = 边长 / 2。半透明面可以看到内部——六面交叠处就是 3D 结构的证明。 直接用鼠标/手指拖动立方体试试。

② 3D 环形轮播（六卡）

排布公式：rotateY(i × 360/N) translateZ(半径R)。 R 的经验公式 = 卡片宽 / 2 / tan(π/N)（N=6 时约等于卡宽 1.87 倍）。 转盘本体再整体 translateZ(-R) 后移，让"当前卡"落在透视面上。

③ translateZ 层深：三层视差

三层分别位于 z = −120 / 0 / +90。在场景上移动鼠标：整个 world 轻微倾斜， 由于三层 z 不同，倾斜在屏幕上的投影位移量不同——这就是"视差"。 远层用 scale 补偿推远造成的视觉缩小。
