伪元素四剑客：::before / ::after / ::marker / ::placeholder

伪元素创建"不在 DOM 树里的虚拟盒子"，装饰与内容分离的最佳工具。

① attr() 角标徽章 —— 数据在属性里，样式在伪元素里

JS 只需更新 data-count 属性，角标内容自动同步；删除属性则角标消失。这就是"content 由结构决定"的设计思想。

🛒 购物车
✉️ 消息
🔔 通知（无角标）

.icon-btn[data-count]::after {
  content: attr(data-count);   /* 属性值 → 内容，样式与数据解耦 */
  position: absolute; top: -7px; right: -7px;
  min-width: 20px; height: 20px;
  background: #e17055; border-radius: 999px;
}

② counter() 计数器步骤条 —— 插入删除自动重排

编号由 counter-reset（父级初始化）+ counter-increment（每项 +1）+ counter()（读取）三件套完成，列表项随意增删，编号永远正确。点击条目可切换"已完成"。

  1. 注册账号并完成实名认证
  2. 创建第一个应用，获取密钥
  3. 接入 SDK，配置回调地址
  4. 沙箱环境联调测试
  5. 提交审核，上线发布
.steps { counter-reset: step; }        /* ① 父级清零 */
.steps li { counter-increment: step; } /* ② 每项自增 */
.steps li::before {
  content: "第 " counter(step) " 步";  /* ③ 读取拼接 */
}

③ ::marker 定制列表标记，以及它的天花板

左侧用 ::marker 换内容与颜色；右侧用 list-style:none + ::before 自绘方形渐变标记 —— 当 marker 满足不了设计时，退回 ::before 自由绘制。

::marker 方案（支持 color/font/content）

  • 苹果 —— 脆甜多汁
  • 橙子 —— 维 C 满格
  • 葡萄 —— 串粒饱满

::before 自绘方案（样式自由）

  • 支持任意形状与渐变
  • 可定位、可动画
  • 适合设计规范严格的站点

④ ::placeholder 占位样式 + ::selection 选中高亮

用鼠标拖选这一段文字看看：高亮变成米黄底 + 红字，这是 ::selection 的效果。它只允许 color、background、text-shadow 等少数属性，不能改字号或边距 —— 安全限制是为了保持"选区"的可识别性。
