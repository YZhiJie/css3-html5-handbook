:not / :is / :where / :has 逻辑伪类对比

三个实验区分别对应"优先级差异""父级感知"与"选型速查"。

A · :is 与 :where 的优先级差异

:is(.box-a, .box-b) h3 的优先级是 (0,1,1)（取括号内最复杂的 .box）； :where(...) h3 的优先级是 (0,0,1)。 点击按钮注入一条 (0,0,1) 的 h3 规则：:where 部分被覆盖、:is 部分纹丝不动 —— 这就是两者的本质区别。

:is 版标题

该标题由 :is(.box-a, .box-b) h3 上色，规则优先级 (0,1,1)。

:where 版标题

该标题由 :where(.box-a, .box-b) h3 上色，规则优先级 (0,0,1)。

C · 四兄弟选型速查

伪类 优先级 一句话定位 典型场景
:not() 取括号内最复杂参数 排除法：选中"不满足条件"的 排除最后一项的边框、排除本站外链
:is() 取括号内最复杂参数 合并前缀，任一命中即命中 多容器同样式；列表里的非法项会被宽容忽略
:where() 恒为 0 零优先级默认值，人人可覆盖 组件库/重置样式的"默认层"
:has() 取括号内最复杂参数 向前看：按后代/兄弟选祖先 表单组校验反馈、内容驱动的卡片换肤

口诀：要覆盖用 :where，要合并用 :is，要排除用 :not，要向上用 :has。 另外 :is/:where 的参数列表是"宽容"的 —— 写错一个选择器不会让整条规则作废，而普通选择器列表会整体失效。
