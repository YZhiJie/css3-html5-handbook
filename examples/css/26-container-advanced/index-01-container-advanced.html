2. 容器单位：拖动右下角，文字随容器宽度缩放

⤡ 拖动容器右下角调整宽度，观察标题/正文/标签字号变化

容器查询

响应式排版

clamp(最小值, cqi 比例, 最大值) 让文字在任意容器宽度下比例协调，不再被视口 vw 绑架。

cqi = 容器内联尺寸的 1%。容器 400px 时 5cqi = 20px，800px 时 = 40px，clamp() 兜底极值。

4. @container × @scope：组件自带断点与样式封装

🎴

装哪美哪

@container 管「何时变」，@scope 管「影响谁」。组件样式完全自包含，消费者零配置。

容器 ≥ 420px 时切换为横排（图标左、文字右），窄时竖排。所有样式都在 @scope 内，不污染外部。
