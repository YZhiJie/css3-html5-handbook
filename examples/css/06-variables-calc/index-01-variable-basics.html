自定义属性基础：作用域、继承与 JS 联动

变量是"活的"：改一处，所有引用它的样式自动重算。

实验一 · 继承边界可视化

两卡结构相同。左卡吃 :root 的全局 --accent（蓝）；右卡在自身上覆盖了 --accent: #e84118（红）。拖动全局滑杆时两卡联动，拖动局部滑杆时只有右卡变色 —— 这就是继承的作用域边界。

左卡 · 全局作用域

--accent 未覆盖

继承自 :root → 跟随全局滑杆。

右卡 · 局部覆盖

--accent: #e84118（被覆盖）

继承自 .card-local → 跟随局部滑杆。

--brand = #4361ee

实验二 · JS 运行时写变量（set/get/remove）

按钮分别"设置变量 / 读取变量 / 删除变量"。删除后样式回退到样式表中的值 —— 内联变量优先级高于样式表，但可被移除还原。
