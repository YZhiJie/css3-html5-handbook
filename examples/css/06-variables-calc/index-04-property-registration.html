@property：给 CSS 变量装上"类型系统"

注册类型的变量可以像普通属性一样参与过渡与动画。

① 动画自定义变量：锥形渐变匀速旋转

关键三步：@property --deg { syntax:'<angle>' } 注册类型 → background: conic-gradient(from var(--deg),…) 引用 → @keyframes { to { --deg: 360deg } } 动画变量。未注册时此动画只有首尾两帧（跳变），注册后才是丝滑旋转。

匀速旋转中
--deg: 0deg

提示：拖动滑杆会在动画进行中"劫持"当前角度 —— 松开后旋转从新角度继续，说明变量是真被逐帧写入的。 再点按钮暂停动画，纯手动控制角度。

② 注册 <color>/<length>：平滑过渡　③ 未注册：瞬跳对照

两个色块外观相同、JS 逻辑相同，唯一差别：左块的 --c/--r 已注册类型，右块的 --raw 是普通字符串变量。拖动滑杆对比"平滑插值"与"瞬跳"。

兼容性与降级策略

生产环境的三条军规：

  1. 功能与增强分离：核心交互不依赖 @property，动画失效也必须可用；
  2. 用 @supports 检测：@supports (animation-timeline: none) and (background: paint(x)) 不适用时可改用 JS 检测 CSS.registerProperty 是否存在；
  3. initial-value 必填：漏写或类型不符会让整条注册失效，变量退回"字符串"。
