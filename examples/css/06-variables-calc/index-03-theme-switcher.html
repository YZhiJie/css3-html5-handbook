为什么换肤只需要改一个属性？

页面所有颜色都引用语义变量（var(--bg)、var(--ink)…）， 而 :root[data-theme="dark"] 重新定义了这组变量。 JS 把 <html> 的 data-theme 改成 dark， 继承链刷新 → 全组件换色。组件代码零改动。

记忆策略（生产环境思路）

本页采用三态策略，建议直接搬进项目：

  1. 手动优先：localStorage 里有 light/dark 就用它，用户意志最高；
  2. 系统兜底：没有手动记录时读 prefers-color-scheme；
  3. 先于渲染：初始化脚本内联在 <head>，杜绝 FOUC 白闪；
  4. 容错：读写 localStorage 全部 try/catch，隐私模式下静默降级。
