参数实验台

顺序记忆：inset? → x → y → blur → spread → color。blur 管虚实、spread 管胖瘦；负 spread 会把阴影"收进"元素底下，形成贴地感。

阴影色 
box-shadow: 0px 10px 20px 0px rgba(40,60,120,.30);

三种 hover 抬升写法对照（鼠标扫过感受差异）

写法 A 直接过渡 box-shadow 值（重绘）；写法 B 用伪元素承载深阴影、只动 opacity（合成，推荐）；写法 C 是聚焦环——只动 spread。

A · 过渡阴影值 transition: box-shadow —— 实现最直观，但动画期间每帧都在重绘阴影。 悬停我
B · 伪元素 + opacity（推荐） 深阴影常驻伪元素、透明度切换 —— 动画只发生在合成阶段，滚动列表里更顺滑。 悬停我
C · 聚焦环（spread） blur 保持 0、只放大 spread —— 硬边环，适合选中态与表单聚焦反馈。 悬停我
