text-shadow：霓虹 / 浮雕 / 长投影

文字阴影跟随字形轮廓，是纯 CSS 文字特效的唯一原料（无 spread、无 inset）。

① 霓虹招牌（深底 + 白芯 + 光晕）

霓虹三层结构：白芯（笔画通电感）→ 中距光晕 → 大范围光晕。闪烁动画只动 opacity，绝不动阴影值（每帧重绘会卡）。

深夜食堂 · 营业中

② 浮雕 vs 凹刻：两条阴影的方向互换

凸 = 暗影在下、亮影在上；凹 = 全部反转。这就是"一条高光 + 一条投影"的顶光假设。
