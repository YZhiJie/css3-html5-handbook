drop-shadow：贴轮廓的阴影

box-shadow 投影矩形边框盒；drop-shadow 投影渲染后的 alpha 轮廓。

① 对话气泡：尖角阴影破绽对照

两个气泡结构完全相同（主体 + ::after 三角尖）。左：box-shadow 沿主体矩形投影，尖角在矩形外 → "悬空没影子"；右：drop-shadow 把伪元素并入轮廓 → 尖角同样带阴影。

box-shadow 版（注意尖角） 你好，这个方案里尖角没影子！ 阴影 = 主体矩形。伪元素尖角游离在矩形外，视觉断裂。
drop-shadow 版（浑然一体） 你好，我的尖角也有影子！ 阴影 = 主体 + 伪元素合并后的真实轮廓。

② 内联 SVG 图标：异形轮廓投影

闪电与云朵是 path 绘制的不规则形状。drop-shadow 贴着 path 投影 —— 若用 box-shadow，会得到一个矩形影子（此处省略对照组，脑补即可）。

filter: drop-shadow(0 5px 6px rgba(35,44,61,.35)) —— 一行样式服务任意形状。

③ clip-path 异形卡片：谁裁掉了谁的阴影

左：clip-path 会把 box-shadow 一起裁掉（看不到影子）；右：阴影放到外层容器用 drop-shadow —— 它作用于"裁剪后"的最终轮廓，影子是异形的。

box-shadow 被 clip-path 裁没
代码里写了 box-shadow，但 clip-path 优先 —— 阴影与斜切角一起被裁掉。
外层 drop-shadow 包裹（正确）
阴影作用在裁剪后的轮廓上 —— 斜切角的影子形状是对的。

④ 镂空图形：实心矩形影 vs 空心剪影

圆环中心是透明的。box-shadow 照着矩形画（影子是"实心方饼"）；drop-shadow 按 alpha 剪影画，影子的中心也是空的 —— 处理透明 PNG 插图时同理。

box-shadow：矩形影子，中心被填实。
drop-shadow：影子跟着"甜甜圈"一起镂空。
