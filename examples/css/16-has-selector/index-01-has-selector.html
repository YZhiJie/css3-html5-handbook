:has() 选择器

CSS 的「父选择器」—— 纯 CSS 实现 DOM 反向匹配

示例 1 · 父选择器：有图片的卡片高亮

促销

有标签的卡片

此卡片包含 .card-tag，边框自动变为品红色。

有图片的卡片

此卡片包含 img，边框自动变为紫色。

普通卡片

无标签、无图片，保持默认边框。

.card:has(img) — 包含图片的卡片自动获得紫色边框。
.card:has(.card-tag) — 包含标签的卡片获得品红色边框。

示例 2 · 表单验证状态联动

label:has(input:focus-visible) — 聚焦时 label 边框高亮。
label:has(input:invalid) — 无效时边框变红。
form:has(input:invalid) .submit-btn — 有无效字段时禁用提交按钮。

.grid:has(> :nth-child(3):last-child) — 恰好 3 项时单列大卡片。

示例 4 · 兄弟前置选择器

img:has(+ figcaption) — 后面跟着标题的图片，圆角只在上边，下边与标题连为一体。

示例 5 · 导航子菜单标记

  • 首页
  • 产品
    • 产品 A
    • 产品 B
  • 关于
  • 服务
    • 咨询
    • 开发
    • 运维
li:has(> ul) > span::after — 有子菜单的导航项自动添加 ▼ 箭头。
li:has(> ul):hover > ul — 悬停有子菜单的项时展开子菜单。
