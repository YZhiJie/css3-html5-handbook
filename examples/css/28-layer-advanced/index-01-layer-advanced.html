@layer 进阶

嵌套层 · 匿名层 · revert-layer · 第三方库覆盖

演示 1 · 嵌套层（base → theme → variant）

嵌套层卡片：base 层定义基础样式，theme 层加边框，variant 层改背景为绿色。
最终样式 = base + theme + variant 三层叠加

@layer demo1 { @layer base { } @layer theme { } @layer variant { } } —— 同父层内按声明顺序覆盖。

演示 2 · 匿名层（包裹第三方 CSS）

匿名层卡片：命名层定义背景，匿名层加粉色边框。
匿名层排在所有命名层之后

不带名字的 @layer { } 用于包裹第三方库，避免污染命名层体系。

演示 3 · revert-layer（精确撤销覆盖）

revert-layer 卡片：components 层用 color: revert-layer 回退到 base 层的白色文字，但覆盖背景为红色。

revert-layer 回退到上一层，revert 回退到浏览器默认。

演示 4 · 第三方库样式覆盖

第三方库按钮原本是灰色圆角小，@layer demo4 覆盖为紫色大圆角——无需 !important 或提高特异性。
