@starting-style 入场/离场动画

@starting-style · transition-behavior: allow-discrete · 入场三件套

✅ 当前浏览器支持 @starting-style 与 allow-discrete，全部示例可交互。 ⚠️ 当前浏览器不支持 transition-behavior: allow-discrete（Chrome 117+ / Safari 17.5+ / Firefox 129+）。示例将无动画退化。

示例 1 · 新插入 DOM 自动入场

点击「追加」→ 新节点插入即自动从 opacity:0; translate:-16px 0 淡入滑入。无需 JS 加类、无需 rAF 拆帧。

示例 2 · display: none ↔ block 也能过渡

我可以在 display: none 与 block 之间平滑淡入淡出，关键是 transition: display .3s allow-discrete。

隐藏时先播离场动画再切 display；显示时从 @starting-style 起点淡入。

示例 3 · Popover 进出场三件套

入场三件套演示

打开：从 scale:.9 + 透明 放大淡入
关闭：缩回 .9 淡出后退出 top layer

零 JS：终态 + :not(:popover-open) 离场态 + @starting-style :popover-open 入场起点。

示例 4 · Toast 自动消失（transitionend 清理）

入场自动淡入；2.4 秒后加 .leaving 播离场动画，transitionend 后自动 remove()。CSS 时长是唯一事实源。
