示例 2 · active-view-transition-type 类型化转场

不同转场类型触发不同根动画：expand 为圆形扩散，collapse 为圆形收缩，无类型为默认淡入淡出。

示例 3 · MPA 跨页转场（@view-transition { navigation: auto }）

⚠️ 本示例为单文件 HTML，无法直接演示跨页导航。
跨页 View Transitions 需要两个同站 HTML 页面，且各自在 CSS 中声明：
@view-transition { navigation: auto; }
然后在 A 页点击 <a href="b.html"> 跳转，浏览器自动在两页之间拍快照并补间动画。
建议：复制本文件为 b.html，修改标题后通过 localhost 访问体验。

关键限制：仅同站同源、非 download、非 target="_blank"、非 302 重定向的导航才会触发。
