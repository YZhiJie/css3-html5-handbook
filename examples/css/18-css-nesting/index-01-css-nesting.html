示例 1 · 基础嵌套：后代 / & 拼接 / 悬停

普通卡片
标题样式来自嵌套规则 .n-card { .n-title {} }，悬停卡片边框变紫（&:hover）。
精选卡片
&.featured 拼接为 .n-card.featured（同元素），其内部的 .n-title 展开为 .n-card.featured .n-title。
&.featured（无空格）= 同一个元素加状态；.featured（有空格）= 后代元素。一字之差，语义完全不同。

示例 4 · & 在非开头位置：主题切换反向写

面板标题
这段面板的暗金样式由 [data-theme="gold"] & 嵌套规则驱动—— 写在组件内部，却由祖先属性控制，展开为 [data-theme="gold"] .n-panel。
