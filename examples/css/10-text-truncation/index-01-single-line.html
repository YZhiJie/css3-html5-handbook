示例 01 · 单行省略多场景实验台

三件套人人会背，但"为什么在 flex/grid/table 里不生效"才是真正的考点。

当前：错误写法

① 普通块级元素width:360px

块级元素宽度由父级/自身 width 决定，是"确定的宽度"，三件套直接生效，不需要任何修复。

这是一段在 360px 宽块级盒子里的长文本：2026 年度产品路线图（内部讨论稿-第三次评审-请以本版为准）.docx

② flex 行方向子项flex:1 + 固定按钮

错误写法下标题拒绝收缩（min-width:auto=min-content），按钮被挤出容器；开启修复后标题在可用宽度内省略。

一份标题特别特别长的需求文档最终版 v17（请各位同事尽快审阅并回填意见）.docx

③ grid 两列布局1fr 1fr

错误写法下 1fr 的下限是 auto（=min-content），长 URL 把两列一起撑宽；修复后轨道可缩到 0，省略生效。

短标题
https://example.com/api/v2/repositories/2026/very/long/resource/path?token=abcdef0123456789

④ 表格单元格table-layout

auto 布局下列宽由内容决定（长链接独占宽度）；fixed 布局下按 colgroup 34:42:24 分配，各列独立省略。

⑤ button 元素UA 默认 nowrap

button 默认 white-space:nowrap，省略"碰巧"能用——但依赖浏览器默认值是脆弱的，修复写法显式声明。

提示：若设计要求按钮文字可换行，需要显式 white-space: normal，因为默认值"拦着"你。

实验结论
  • 单行省略 = 三件套（nowrap + overflow:hidden + text-overflow:ellipsis）+ 确定的宽度。
  • flex 行子项加 min-width:0；grid 子项加 min-width:0 或轨道写 minmax(0,1fr)；table 加 table-layout:fixed。
  • 徽标与 title 全部由 scrollWidth/clientWidth 检测驱动：只有真正被截断的元素才标红、才挂 title。
