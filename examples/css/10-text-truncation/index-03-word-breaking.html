② 关键实证：break-word 为什么救不了 flex 溢出

三行都只给内容 flex:1 且不写 min-width:0。 break-word 的断行点不参与 min-content 计算， flex 仍按最长单词宽度拒绝收缩；anywhere 参与计算所以能缩； 经典做法是 break-word + min-width:0。

③ 特殊字符实验：nbsp / 零宽空格 / 软连字符 / pre-wrap

富文本事故三件套：不可断空格撑爆布局、零宽空格优雅断 URL、软连字符给英文断词加连接号。

&nbsp; 连续不可断空格

价格：100        元（含税与服务费）

多个 &nbsp; 形成不可断串，窄容器中整体溢出。富文本编辑器导出的 HTML 高频事故源。

​ 零宽空格（ZWSP）

https://example.com/​api/v2/​repositories/​2026Q3/​resource

在每个 / 后插入 &#8203;：视觉不可见，却告诉浏览器"这里可以断"。复制文本时零宽字符会被带走，敏感场景慎用。

&shy; 软连字符（lang="en"）

Inter­national­ization is often abbreviated as i18n, and local­ization as l10n.

&shy; 平时隐形，恰好在该点折行时显示为 -，比硬连字符优雅。

pre-wrap：保留用户输入的换行与空格

收货人：张三 地址：北京市 海淀区 中关村大街 1 号 备注：请在工作日白天送达

white-space:pre-wrap 保留换行符与连续空格，同时允许长行自动折回——用户评论、地址、代码片段必备。

pre-line：只留换行，合并空格

第一行：普通文本 第二行：多余空格 会被合并，但手动换行保留

pre-line 是 pre-wrap 的"宽松版"：连续空格回归 normal 规则，只保留显式换行。

CJK：keep-all 让"词"不断

我爱北京天安门，天安门上太阳升。Great Wall 与万里长城。

word-break:keep-all 让中文标点/词组之间不断行，适合标题；正文使用会造成巨大空白。
