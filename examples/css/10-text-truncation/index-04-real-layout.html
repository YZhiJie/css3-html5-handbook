示例 04 · 文本截断综合实战

卡片、表格、文件列表、标题排版——把本章知识点组装进真实页面。

① 电商商品卡片：标题 2 行 + 描述 3 行 + 底部省略行

所有卡片文字区行数确定、底部 margin-top:auto 钉底，网格里任意卡片严格对齐；店铺名超长时左侧省略、购买按钮永不收缩。

② 订单表格：table-layout:fixed 多列各自省略

列宽由 colgroup 决定（36:20:30:14），每列独立省略互不干扰；悬浮查看全文用自定义气泡。

商品买家收货地址金额

③ 文件名中段截断：保留头部与扩展名

纯 CSS 只能尾部省略，会丢掉最重要的扩展名信息；这里用 Canvas measureText 二分测量，输出 aaa…bbb.js。拖动滑杆改变可用宽度。

可用宽度 300px

④ text-wrap 标题平衡与孤行优化 特性检测中

balance 让两行标题行长尽量均衡（适合 ≤6 行的标题）；pretty 避免段落末行孤字。均为渐进增强，旧浏览器自动退回普通换行。

普通 wrap（对照）

新一代旗舰降噪耳机发布：续航四十小时并支持空间音频与多设备无缝切换
这是一段用于演示 pretty 效果的正文段落。当最后一行只剩下一个字挂在那里时，排版上称为孤行，pretty 会调整前面各行的断点，让末行至少保留两个以上的字，使段落边缘看起来更稳。
