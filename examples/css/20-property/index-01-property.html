@property

注册后的 CSS 变量：有类型、可动画、可继承

示例 1 · 颜色过渡：注册变量平滑补间，未注册瞬间跳变

已注册 <color>（点击切换）
未注册字符串（点击切换）
左侧注册 @property --fill { syntax: "<color>" }，过渡平滑； 右侧未注册，浏览器视为字符串，0.8s 后瞬间变色——没有中间帧。

示例 2 · 驱动 color-mix() 百分比参数

background: color-mix(in oklab, #22d3ee var(--mix), #7c3aed)， 注册 --mix: <percentage> 后可直接 transition: --mix。
