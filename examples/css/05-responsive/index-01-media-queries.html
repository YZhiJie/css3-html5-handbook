② clamp() 流体标题（零断点）

font-size: clamp(2rem, 5vw + 1rem, 4.5rem) —— 1rem 是固定底座、5vw 是流动部分、两端钳制。窗口越宽标题越大， 但永远在 [2rem, 4.5rem] 之间。

③ 视口单位：vw / vmin / vmax

25vw = 视口宽 25%；vmin 取宽高较小者、vmax 取较大者。 拖动窗口或旋转设备模拟，观察三种单位的差异。
width: 25vw
width: 34vmin
width: 18vmax

另有高度单位族：vh（基础）、dvh（动态，随移动端地址栏收放）、 svh（地址栏展开时最小值）、lvh（地址栏收起时最大值）。

④ 移动端地址栏坑：100vh vs 100dvh

iOS Safari 的 100vh 包含被地址栏遮挡的部分——首屏按钮会被顶出屏幕。 解法：height: 100vh; height: 100dvh; 双写（旧浏览器用前者，新浏览器用后者）。 在 DevTools 设备模拟（iPhone）中对比最明显。
