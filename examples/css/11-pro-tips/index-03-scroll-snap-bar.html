② 纵向全屏分屏（局部滚动容器）

在下方盒子内滚动：每屏一个主题，停顿感来自 snap。可切换 mandatory 感受"强制"的副作用。

纵向吸附
SCREEN 01

proximity 为什么是长内容首选

mandatory 要求滚动停止后必须落在 snap 点。若某一屏内容高于容器，超出部分在部分浏览器上难以停留查看；proximity 仅在靠近时吸附，既保留段落感，又不牺牲自由滚动。

SCREEN 02

吸附边：start / center / end

scroll-snap-align 决定元素的哪条边与容器对齐。全屏分页用 start；居中画廊用 center；时间轴底部对齐的卡片可用 end。

SCREEN 03

固定头与安全区

本页顶部导航高 60px，html 上声明 scroll-padding-top 后，所有锚点跳转与页面级吸附统一下移，标题不会被遮挡。

SCREEN 04

减少动态效果

scroll-behavior:smooth 与 snap 动画在 prefers-reduced-motion 下应被收敛，媒体查询把平滑行为退回 auto。

③ 代码要点速查

本页实际生效的核心声明：

固定头避让 + 平滑锚点
html { scroll-behavior: smooth; /* 锚点平滑 */ scroll-padding-top: 72px; /* 固定头 60px + 12px 间隙 */ } @media (prefers-reduced-motion: reduce) { html { scroll-behavior: auto; } /* 无障碍：尊重系统设置 */ }
横向轮播
.carousel { display: flex; overflow-x: auto; scroll-snap-type: x mandatory; scroll-padding-left: 4px; } .slide { flex: 0 0 78%; scroll-snap-align: start; scroll-snap-stop: always; }
隐藏滚动条仍可滚动
.bar-hidden { scrollbar-width: none; -ms-overflow-style: none; } .bar-hidden::-webkit-scrollbar { display: none; }
