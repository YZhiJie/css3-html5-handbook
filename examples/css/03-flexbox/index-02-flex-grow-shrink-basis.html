flex 三属性与简写陷阱

flex-grow（放大权重）· flex-shrink（收缩权重）· flex-basis（分配前基准）——一切差异都从 basis 起点开始。

1. flex: 1 与 flex: auto 的区别

三列内容长短刻意不同。flex: 1 展开为 1 1 0%（基准 0，剩余空间纯均分 → 等宽）； flex: auto 展开为 1 1 auto（基准 = 内容宽，先按内容占位再分剩余 → 内容多者更宽）。

2. flex-grow 权重实验

左右两块为 flex: none 刚性块，中间块 grow 值可调： 剩余空间按 grow 权重（此处其余项为 0）全部分给中间块；拖到 0 观察它"退回内容宽"。

3. min-width: auto 溢出坑与修复

flex item 的默认最小尺寸是内容的 min-content：关闭修复时， 标题把"删除"按钮挤出容器；开启修复后 min-width: 0 允许标题收缩，配合 overflow: hidden + text-overflow: ellipsis 出省略号。
