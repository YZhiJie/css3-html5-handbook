Flex 实战三合体

导航栏 · 等高卡片 · 表单行——生产中出现频率最高的三个 Flex 组件模式。

1. 响应式导航栏

结构：logo（flex:none） + 菜单（flex:1 内部居中） + 按钮组（flex:none）。拖窄窗口：菜单项先组内换行，再整块掉行，永不溢出。

菜单能精确居中，是因为左右两块刚性、中间块 flex:1 吃掉全部剩余空间—— 左右宽度不等也不会导致菜单偏移（剩余空间被夹逼居中）。

2. 等高分栏卡片（按钮贴底）

三张卡描述字数差异巨大，但卡高一致（外层默认 align-items: stretch）， 按钮靠 margin-top: auto 统一压到底部。

3. 表单行（基线对齐）

点下方按钮把 label 字号放大，观察输入框文字仍与 label 贴在同一条基线上—— 这正是 align-items: baseline 与 center 的排版级差别。
