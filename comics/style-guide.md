# 漫画风格规范 · 霓虹墨 Neon Ink

> 「前端漫画实验室」系列美术宪法。CSS3 × HTML5 漫画剧场 21 话（CSS 11 话 + HTML 10 话）全部遵守本规范，保证风格统一、可批量生产。
>
> 定妆稿：[风格样板页](samples/style-sample-page.svg) ｜ [角色设定表](samples/character-sheet.svg) ｜ [配色与构图法则](samples/palette-focal-rules.svg)
>
> 版本：v1.0.0（2026-09-27）

## 0. 一句话定位

**深墨底打光，霓虹只给主角。**

- 高端感来自克制：60/30/10 配比，霓虹永远只落在「当格主角」上
- 冲击力来自对比：深底 + 高亮描边 + 半调网点，焦点一格独亮
- 易读性来自秩序：一格一焦点，编号、气泡、箭头引导 1→2→3 视线动线

## 1. 画布与版式规格

所有话统一 `viewBox="0 0 1200 840"`，坐标即规格：

| 分区 | 坐标 | 内容 |
| --- | --- | --- |
| 顶部横幅 | y 0–96 | 系列副标基线 y36（15px 灰）、话数标题基线 y74（30px 白粗）、EP 徽章 `rect(1020,26,140,44)` 圆角 22 |
| 上排双格 | y 120–370 | 格1 `x40 w556`、格2 `x616 w544`，格间距 20 |
| 主格（格3） | y 390–620 | `x40 w1120`，全宽戏剧格 |
| 知识条 | y 640–792 | `x40 w1120 h152`，琥珀底收束 |
| 通用 | — | 页边距 40；格圆角 16、描边 `#334155` 3px；格内元素距边 ≥16 |

多设备适配三原则：

1. **矢量自适应**：SVG 以 `width:100%; height:auto` 嵌入，手机到宽屏均清晰，无需多套切图。
2. **自带画布**： artwork 自含深色背景，不依赖宿主页面主题——明暗模式、GitHub / VS Code / 浏览器渲染结果一致。
3. **单文件自包含**：无外链图片、字体、脚本，双击即看，可单话下载离线阅读。

## 2. 配色系统

### 2.1 色板

| 角色 | Hex | 用途 |
| --- | --- | --- |
| 墨底 Ink | `#0B1220` | 页面画布、横幅底 |
| 面板 Panel | `#131C2E` | 分格底色、卡片 |
| 电光青 Cyan | `#22D3EE` | CSS 篇主色；编号①、焦点描边、主轴/流程箭头 |
| 幻紫 Violet | `#A78BFA` | CSS 篇辅色；编号②、代码标签 |
| 品红 Magenta | `#F472B6` | 点缀：焦点动线箭头、警示强调、像素酱卫衣 |
| 琥珀 Amber | `#FBBF24` | HTML 篇主色；编号③、知识条底、星光 |
| 机器人橙 | `#FB923C` | 标签君机身；HTML 篇辅色 |
| 语义红 | `#F87171` | 仅易错点/错误标记（! ? 与红描边） |
| 语义绿 | `#4ADE80` | 仅代码成功输出（如 `</>` 屏显） |
| 降级灰 | `#475569` / `#64748B` | 非焦点元素、占位内容 |

文字色：深底用白 `#F8FAFC` / 浅 `#CBD5E1` / 注释灰 `#94A3B8`；白气泡与琥珀条上用墨 `#0B1220`（条目 `#451A03`）。

### 2.2 配比 60 / 30 / 10

60% 墨底 + 30% 面板灰 + 10% 霓虹。一话内霓虹色相不超过 3 种同时高亮；「重要 = 更亮」是唯一权重语言。

### 2.3 篇章主题色

- **CSS 篇（EP.01–11）**：主 电光青，辅 幻紫
- **HTML 篇（EP.12–21）**：主 琥珀，辅 机器人橙
- **跨篇恒定锚点**（全系列不动）：横幅左侧双色霓虹边条（上青下品红）、编号圆片 ①青 ②紫 ③琥珀、知识条琥珀底

## 3. 字体与文字

- 中文栈：`'PingFang SC','Hiragino Sans GB','Microsoft YaHei',sans-serif`
- 代码栈：`'SFMono-Regular',Menlo,Consolas,monospace`
- 字号表（1200 坐标系，禁止更小）：横幅标题 30 bold ｜ 横幅副标 15 ｜ EP 徽章 19 bold ｜ 面板标题 19 bold ｜ 对话 15 ｜ 面板注释 12.5 ｜ 知识条标题 20 bold ｜ 知识条条目 15 ｜ 色值/代码 12–13 mono ｜ 全局下限 11
- 行宽红线：白气泡（宽 218）每行 ≤13 个汉字、每气泡 ≤2 行；所有文字距容器边 ≥16
- XML 转义：文本节点中 `<` `>` `&` 必须写作 `&lt;` `&gt;` `&amp;`（如 `</>` 写作 `&lt;/&gt;`），禁止裸字符

## 4. 角色设定

| 角色 | 身份 | 主色 | 信条 |
| --- | --- | --- | --- |
| **像素酱** Pixel | CSS 造型师 | 青紫双色发 + 品红卫衣 | 「样式的事，交给我」 |
| **标签君** Taggy | HTML5 结构师 | 橙色机身 + `< >` 眼罩 | 「骨架我来搭，稳」 |
| **码叔** Prof. Moo | 划重点担当 | 琥珀羽毛 + 学士帽 | 「带走三句，就够了」 |

出场与绘制规则：

1. 每话至少一位主角担纲剧情；码叔只在底部知识条出镜（结尾仪式感）。
2. 表情服务教学：**困惑 = 痛点格，讲解 = 机制格，开心 = 结果格**；夸张有度，剪影可识别。
3. 比例：主角立绘高约 140 单位，脚底基线 y=345，头身比约 1:1.6；完整绘制代码见 [character-sheet.svg](samples/character-sheet.svg)，量产时整组 `<g>` 复制后平移/换表情。
4. 表情库：像素酱（日常/惊讶/开心）、标签君（日常/激动）、码叔（开讲/严肃）。

## 6. 每话叙事结构（映射知识点五要素）

| 漫画部件 | 教学要素 | 内容要求 |
| --- | --- | --- |
| 顶部横幅 | — | 系列名 + 话数标题 + EP 徽章（篇章主色） |
| 格1 · 痛点现场 | **易错点警示** | 真实踩坑场景，红 `!`/`?` 标记，主角困惑表情 |
| 格2 · 机制登场 | **核心概念图解 + 关键原理分步** | 数据结构/流程图解，术语与正文 docs 严格一致 |
| 格3 · 落地收束 | **常见应用场景展示** | 对比或成果呈现，有且仅有一个焦点 |
| 知识条 | — | 码叔划重点：三条必须带走的结论 |
| 讲解 MD | **实践操作引导** | 见下方模板 |

讲解 MD 固定结构（45–100 行，必含「码叔划重点」「自测」小节）：

```text
# 漫画 · 第 N 话 标题
> 对应正文：[docs 链接] ｜ 原画：[本话 SVG]
## 登场角色      → 本话出场角色一句话介绍
## 剧情梗概      → 2–3 句
## 分格解读      → 格1/格2/格3 逐格讲透原理
## 码叔划重点    → 3 条
## 自测一题      → 问 + 答
## 动手实验      → 链接 examples/ 对应目录的可运行示例
## 下一话预告    → 1–2 句
```

## 7. 制作与校验清单

每话交付前逐项过：

- [ ] `viewBox="0 0 1200 840"`、`xmlns` 正确，`xmllint --noout` 良构
- [ ] 可见文本无裸 `<` `>` `&`
- [ ] EP 徽章编号与本话一致；分区坐标符合第 1 节规格
- [ ] 行宽/字号红线达标；一格一焦点；霓虹 ≤3 色同屏高亮
- [ ] 讲解 MD 结构完整，`../../docs` 与 examples/ 链接可达
- [ ] 在 `comics/manifest.json` 登记（`samples/` 目录仅作定妆参考，不参与话数编号与校验）

## 8. 分发与适配

- **在线阅读**：GitHub / VS Code / 浏览器直接渲染 SVG；后续提供 `comics/index.html` 在线阅读器（分篇浏览 + 单话 SVG 下载入口）。
- **离线下载**：SVG 与讲解 MD 成对自包含，整目录拷走即离线可用，零运行时依赖。
- **导出打印**：深底画布导出 PNG/PDF 视觉不变；矢量保证任意倍率清晰。
